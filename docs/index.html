Importer

Sessions de ta montre ou d'une autre appli

Depuis la Galaxy Watch

1. Enregistre ta session sur la montre avec une appli qui exporte en GPX (par ex. Strava pour Wear OS, ou une appli de tracé GPS).
2. Récupère le fichier GPX sur ton téléphone (depuis Strava web : ⋯ › Exporter GPX).
3. Importe-le ici : toutes les stats wingfoil sont recalculées (Vmax, 10 s, 100 m, 500 m, temps sur le foil, virages…).

Conseils sur l'eau

• Garde l'écran allumé (l'appli l'empêche de se mettre en veille) : Android coupe le GPS des applis web quand l'écran s'éteint.
• Baisse la luminosité au minimum et mets le téléphone dans une pochette étanche, fixée au bras ou au harnais.
• Attends le point vert « GPS précis » avant de partir.
• Les sessions sont stockées sur ce téléphone : pense à l'export JSON de temps en temps.
